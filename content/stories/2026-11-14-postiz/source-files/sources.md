## Wording notes
- "Host for free": the software is free; the README says you still pay for your own server. The script says "host this app for free", which matches the README's "free forever" for the self-hosted edition. Flag if you want "the code is free" instead.
- "People pay" / "paid subscriptions" → "active subscriptions": TrustMRR counts active subscriptions, which can include 7 day trials.
- "Every platform" → "over thirty platforms" (postiz.com says 30+).
- "Free." alone could not be voiced clearly (Whisper heard other words in 9 of 9 takes) → "Yes. Completely free."
- Whisper hears "Postiz" as "Postus" in the voice. Official pronunciation not found on postiz.com; check by ear.
- "Because most people never want to touch a server" is our read of why, not a sourced claim.
